# Movie Ticket Booking Management Application

## Project Overview

The **Movie Ticket Booking Management Application** is a workflow-based application developed using **Pega Platform** to manage movie ticket booking requests efficiently.

The application is designed to streamline the booking process from movie and show selection through seat selection, booking confirmation, payment, and cancellation. It provides a centralized workflow for submitting, tracking, and managing movie ticket booking requests.

## Problem Statement

Traditional movie ticket booking and management processes can involve manual activities, limited visibility, and inefficient communication between customers and staff.

This project uses **Pega Platform's case management and workflow automation capabilities** to provide a structured and centralized solution for managing movie ticket booking requests.

## Project Objectives

* Allow users to submit movie ticket booking requests
* Manage movie and show information
* Check show and seat availability
* Calculate booking costs
* Capture customer booking confirmations
* Process booking requests
* Track booking status
* Notify customers about booking confirmation
* Support booking cancellation
* Provide SLA-based workflow management

## Application Workflow

```text
Movie Selection
      ↓
Show Selection
      ↓
Check Show Availability
      ↓
Seat Selection
      ↓
Calculate Booking Cost
      ↓
Confirm Booking Request
      ↓
Process Ticket Booking
      ↓
Booking Confirmation
      ↓
Customer Notification
      ↓
Cancellation / Refund
```

## Skill Wallet User Stories Implemented

The project consists of the following user stories:

### US-001: Submit Movie Ticket Request

Allows users to submit a new movie ticket booking request.

### US-002: Check Show Availability

Provides a workflow for checking the availability of movie shows.

### US-003: Calculate Booking Cost

Handles the calculation of the booking cost based on the booking details.

### US-004: Confirm Booking Request

Captures confirmation from the customer before the booking is finalized.

### US-005: Maintain Movie and Show Data

Supports management of movie and show-related information.

### US-006: Review Booking Details

Allows staff to review submitted booking information.

### US-007: Process Ticket Booking

Processes the booking request through the application workflow.

### US-008: Notify Booking Confirmation

Provides customer notification after booking confirmation.

### US-009: Define Booking SLA

Supports service-level requirements for processing booking requests.

### US-010: Route Booking Request by Show Type

Supports routing of booking requests based on show-related requirements.

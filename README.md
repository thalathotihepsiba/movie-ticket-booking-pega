# 🎬 Movie Ticket Booking Management Application

> A workflow-based movie ticket booking application developed using **Pega Platform** to manage booking requests, show availability, booking confirmation, processing, and customer notifications.

---

## 📌 Project Overview

The **Movie Ticket Booking Management Application** is a workflow-driven application developed using **Pega Platform**.

The project demonstrates how Pega **Case Management, App Studio, Blueprint, Data Modeling, Workflow Automation, SLA Management, and request routing** can be used to build a structured business application.

The application manages the movie ticket booking journey from submitting a request through availability checking, cost calculation, confirmation, booking processing, and customer notification.

---

## 🎯 Objectives

* Submit movie ticket booking requests
* Check movie show availability
* Calculate booking costs
* Confirm booking requests
* Maintain movie and show information
* Review booking details
* Process ticket bookings
* Notify customers about booking confirmation
* Define booking SLAs
* Route requests based on show type

---

## 🔄 Application Workflow

```text
Submit Movie Ticket Request
            ↓
Check Show Availability
            ↓
Calculate Booking Cost
            ↓
Confirm Booking Request
            ↓
Review Booking Details
            ↓
Process Ticket Booking
            ↓
Booking Confirmation
            ↓
Customer Notification
```

## 🚀 User Stories

### US-001 — Submit Movie Ticket Request

Allows users to submit a new movie ticket booking request.

### US-002 — Check Show Availability

Allows the availability of movie shows to be checked before continuing with the booking.

### US-003 — Calculate Booking Cost

Calculates the cost associated with the movie ticket booking.

### US-004 — Confirm Booking Request

Captures confirmation before the booking request proceeds for processing.

### US-005 — Maintain Movie and Show Data

Supports maintaining movie and show information used during the booking process.

### US-006 — Review Booking Details

Allows booking details to be reviewed before the booking is processed.

### US-007 — Process Ticket Booking

Processes the ticket booking request through the configured workflow.

### US-008 — Notify Booking Confirmation

Provides customer notification after the booking is confirmed.

### US-009 — Define Booking SLA

Defines service-level requirements for processing booking requests within the expected timeframe.

### US-010 — Route Booking Request by Show Type

Routes booking requests according to the configured show type.
